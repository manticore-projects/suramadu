Suramadu.

Swing in the Browser

Suramadu runs Java Swing applications on the server and delivers them to a browser as pure HTML5. The application runs unchanged; the browser draws the window and sends back mouse and keyboard input. No plugins, no client installation, no changes to application source.

This is the default landing page of a fresh installation. Once an application is configured it will be served from its own path.

Getting started

  • Configure your application in suramadu.config.
  • Adjust server settings in suramadu.properties and jetty.properties.
  • Restart with ./run.sh restart.
